# Локализация на русский язык для OpenCart 4.x и ocStore 4.x

Полный пакет русской локализации для панели администратора и витрины интернет-магазина на базе OpenCart 4.x и ocStore 4.x (включая версию 4.1.0.3-Beta).

---

## 🚀 Установка

Вы можете установить данный языковой пакет двумя способами: автоматически через панель управления или вручную, скопировав файлы на сервер.

### Способ 1. Автоматическая установка (Рекомендуется)

1. Скачайте репозиторий в виде ZIP-архива.
2. Убедитесь, что внутри архива файлы `admin`, `catalog` и `install.json` находятся **в корне** (без промежуточной папки).
3. Переименуйте архив, чтобы его имя заканчивалось на `.ocmod.zip` (например, `russian-lang.ocmod.zip`).
4. Перейдите в административную панель вашего сайта: **Extensions** ➔ **Installer** (Расширения ➔ Установка расширений).
5. Нажмите кнопку **Upload** (Загрузить) и выберите ваш архив `.ocmod.zip`.
6. После успешной загрузки нажмите кнопку **Install** (Установить) в списке ниже.

### Способ 2. Ручная установка

1. Скачайте и распакуйте архив с языковым пакетом.
2. Скопируйте папки `admin` и `catalog` в корневую директорию вашего сайта (с сохранением структуры).

## ⚙️ Активация и настройка языка

После того как файлы загружены на сайт, язык необходимо зарегистрировать в системе:

1. Перейдите в раздел **System** ➔ **Localisation** ➔ **Languages** (Система ➔ Локализация ➔ Языки).
2. Нажмите кнопку **Add New** (Добавить новый `+`) в верхнем правом углу.
3. Заполните поля формы следующими значениями:
   * **Language Name:** `Русский`
   * **Code:** `ru-ru`
   * **Locale:** `ru-RU,ru,ru_RU.UTF-8`
   * **Status:** `Enabled` (Включено)
   * **Sort Order:** `1` (или любое другое значение для приоритета при выборе)
4. Нажмите кнопку **Save** (Сохранить).

### Установка русского языка по умолчанию

Если вы хотите сделать русский язык основным для вашего интернет-магазина и панели администратора:

1. Перейдите в **System** ➔ **Settings** (Система ➔ Настройки).
2. Нажмите кнопку **Edit** (Редактировать) напротив вашего магазина.
3. Откройте вкладку **Local** (Локализация).
4. Установите следующие значения:
   * **Language** (Язык витрины): `Русский`
   * **Administration Language** (Язык админки): `Русский`
5. Нажмите кнопку **Save** (Сохранить).
